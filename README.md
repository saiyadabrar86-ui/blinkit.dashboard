# Blinkit Quick-Commerce Grocery Sales Analysis 🛒📈

## 📌 Project Overview
This final-year engineering data science project transforms raw, unstructured quick-commerce transactional records into an interactive business intelligence architecture. It models operational performance velocity across diverse consumer retail tiers.

## 🛠️ Tech Stack & Engineering Layer
- **Core Visualization Engine:** Microsoft Power BI Desktop
- **Data Transformation Pipeline:** Power Query ETL (M Language Engine)
- **Analytical Compute Layer:** Advanced Data Analysis Expressions (DAX)
- **Predictive Engine:** Native Time-Series Exponential Smoothing (ETS Model)
